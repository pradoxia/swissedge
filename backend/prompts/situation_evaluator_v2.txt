## EVALUATION INSTRUCTIONS

1. **If playbook_status is "out_of_scope":**
   - Set recommendation: "OUT_OF_SCOPE"
   - Set evaluator_confidence: "INSUFFICIENT"
   - Populate routing_decision.out_of_scope_reason
   - Return minimal checklist_results and risk_flags
   - Skip investment analysis

2. **If playbook_status is "detection_only":**
   - Set recommendation: "DETECTION_ONLY"
   - Set evaluator_confidence: "PARTIAL"
   - Record filing details in evidence_sources
   - Populate checklist_results with detection checks only
   - Flag all evaluation items as human_review_required
   - Skip investment analysis

3. **If playbook_status is "routing_detection_only":**
   - Confirm routing decision is correct
   - Set recommendation: "WATCHLIST" (gateway playbook)
   - Set evaluator_confidence: "PARTIAL"
   - Populate routing_decision.routed_to if applicable
   - Skip deep investment analysis

4. **If playbook_status is "partial":**
   - Perform ONLY checks in allowed_checks list
   - For each prohibited check: add to human_review_required
   - Set evaluator_confidence: "PARTIAL"
   - Set recommendation based on filing-evaluable checks only
   - Flag valuation/NAV/recovery/mandate/broker/tax/legal items

5. **If playbook_status is "evaluator_ready":**
   - Perform all checks in allowed_checks list
   - Calculate metrics if required data exists (spread, IRR)
   - Set evaluator_confidence: "FULL" if all data available
   - Set recommendation based on full evaluation
   - Flag only items truly requiring human judgment

6. **For all modes:**
   - Check for amendments (SC TO-I/A, 8-K/A, DEFM14A/A)
   - Record all evidence sources used
   - Flag risks from relevant_risk_patterns
   - Use UNKNOWN when data is missing, not assumptions
   - Include required disclaimer exactly as specified

## RECOMMENDATION CRITERIA

**PASS**: Non-binding offer, IRR <10%, critical data missing, outside scope
**WATCHLIST**: Preliminary filing, regulatory review pending, non-definitive
**DEEP_RESEARCH**: Definitive agreement, IRR >10%, manageable risks, evaluator_confidence FULL or PARTIAL with acceptable human-review items
**HUMAN_REVIEW_REQUIRED**: Critical valuation/NAV/recovery items block evaluation
**OUT_OF_SCOPE**: Situation outside validated playbook scope
**DETECTION_ONLY**: No evaluation methodology exists for this situation type

Respond with ONLY the JSON output. No preamble, no explanation, no markdown code blocks.
