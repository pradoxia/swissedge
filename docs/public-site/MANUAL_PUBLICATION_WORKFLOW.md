# SwissEdge Manual Publication Workflow

> Public-safe operational checklist. No API publishing. No automatic publishing.

## Safe Manual Path

1. Private ResearchCase remains internal.
   - Internal notes, identifiers, source registry details, and operational metadata stay private.

2. PublicArticleDraft is created privately.
   - The draft is the public-safe editorial surface, not the internal research workspace.

3. Dani or an editor reviews the draft.
   - Review title, body, source descriptions, risk language, checklist, and disclaimer before any public use.

4. Draft language must remain educational.
   - Avoid financial advice, transaction-direction wording, price targets, performance claims, urgency, and hype.

5. Draft must not expose private material.
   - Exclude private notes, internal IDs, system metadata, secrets, raw environment values, infrastructure details, and unpublished research material.

6. Approved copy may be moved manually.
   - After human approval, copy may be manually pasted into Substack or a future public-site content file.

7. No API publishing.
   - Do not connect Substack API or any other posting API unless a future sprint explicitly scopes it.

8. No auto-publish.
   - No content should appear publicly because of a cron job, scanner event, model output, or build step alone.

9. Final human checklist before publication.
   - Educational disclaimer present.
   - Manual review date present.
   - What is known is sourced.
   - What is unknown is not empty.
   - What would change the research view is included.
   - Risks are documented.
   - Source quality is visible.
   - No private or operational metadata is present.
