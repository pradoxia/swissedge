# SwissEdge Glossary

- ResearchCase: durable research work object; primary Investment Platform V2 unit.
- SpecialSituation: legacy/evaluation signal row, often created by scanner/evaluator flows.
- Research Inbox: read-only or triage queue centered on ResearchCases.
- investment_sources: future operational source registry for SEC, RSS, newsletters, email alerts, websites, manual inputs, and APIs.
- Source-driven intake: process where source inputs create traceable preliminary ResearchCases.
- V2 metadata: ResearchCase fields for source origin, intake method, evidence, official-source status, methodology, duplicate status, and follow-up.
- Agent Ops: future operations layer for rooms, agents, diagnostics, and learning proposals.
- Room: conceptual workspace grouping agents by operational purpose.
- Agent: bounded assistant or service role with inputs, outputs, skills, and guardrails.
- Fontana: future SwissEdge CTO / Project Governor agent.
- Learning proposal: recommended improvement requiring human approval before action.
- Routing audit: check that detected cases map correctly to methodology/playbooks.
- Course-grounded methodology: analysis based on processed course artifacts, not raw transcripts.
- Human-in-the-loop: Dani approves production changes and deployments.
- PublicArticleDraft: private editorial draft generated from documented ResearchCases; not auto-published.
