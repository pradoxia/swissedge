# SwissEdge Publication Workflow

## Workflow

1. ResearchCase is documented internally.
2. PublicArticleDraft is created manually.
3. Draft is reviewed for completeness and safety.
4. Missing disclaimer or directive language blocks approval.
5. Dani performs manual review.
6. Any external publication is manual.

## Rules

- Public drafts only after documented ResearchCase.
- No auto publish.
- No Substack API automation unless separately approved in the future.
- No private metadata in public article.
- No secrets, private URLs, internal IDs, or infrastructure references.
- No buy/sell/hold recommendation language.

## Deferred

- Public site.
- Substack integration.
- Automated publishing.
