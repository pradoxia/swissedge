# Global Checklist

AI-safe summary placeholder. Full processed artifact remains in core/course_index and should only be shared after sanitization.

## Core Checks

- Identify company, ticker, jurisdiction, and source origin.
- Confirm situation type and evidence level.
- Verify official source status.
- Attach or reference documents using metadata only unless snippets are explicitly provided.
- Map to playbook and checklist.
- List missing information.
- List risks.
- Identify key dates, deadlines, milestones, approvals, or catalysts.
- Decide whether case belongs in deep research, monitoring, archive, or further verification.
- Include educational disclaimer.

## Guardrails

- No buy/sell/hold recommendations.
- No raw course transcript text.
- No private infrastructure details.
- No unsupported conclusion when evidence is weak.
