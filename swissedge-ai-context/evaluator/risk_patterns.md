# Risk Patterns

AI-safe summary placeholder. Full processed artifact remains in core/course_index and should only be shared after sanitization.

## Common Risk Families

- Source risk: external/unverified source, missing official evidence, stale filing.
- Transaction risk: financing, approvals, litigation, timing, competing bids, termination conditions.
- Methodology risk: unsupported situation type, detection-only playbook, missing checklist.
- Data risk: missing dates, missing terms, ticker ambiguity, duplicate cases.
- Process risk: stale task, unresolved official-source verification, misleading UI state.
- Publication risk: private metadata, missing disclaimer, directive recommendation language.

## Use

Risks should guide tasks and human review. They must not produce directive financial advice.
